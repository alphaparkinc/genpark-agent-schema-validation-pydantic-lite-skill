# Schema Validation Lite

## Description
Zero-dependency lightweight Schema validator enforcing type safety, required keys, and bounds checking on tool arguments.

## Compatibility
- MCP Version: 2025-12-11
- Python: >=3.10 (Standard Library only)
- Supported Platforms: Claude Desktop, Cursor, LobeChat, Smithery

## Tools
Refer to `client.py` and `mcp_server.py` for full JSON-RPC tool signatures.
